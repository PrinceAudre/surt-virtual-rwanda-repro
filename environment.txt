Environment record for the SuRT-Virtual Rwanda reproducibility artifact.

These are the exact versions used to produce the released environmental layers
(data/) and to run the value-class demonstration (R/demo_value_class.R).

Operating system / platform: x86_64-w64-mingw32 (Windows, 64-bit)
R: version 4.6.0 (2026-04-24 ucrt)

R packages:
  terra          1.9.27
  sf             1.1.1
  exactextractr  0.10.1
  jsonlite       2.0.0

Python fetchers (temperature and NDVI) additionally require Python 3 with the
official `cdsapi` and `earthaccess` clients. These fetch-only dependencies are
not required by the account-free verification command.

To approximate this R environment:
  install.packages(c("terra", "sf", "exactextractr", "jsonlite"))

The full R dependency graph is recorded in `renv.lock`. Run
`python python/run_all_checks.py` for the account-free labelling, fixture
pipeline, and checksum checks. The same command is run in GitHub Actions.
